# Getting started

Install from the local checkout using `bash install.sh` on macOS/Linux or `bash install-win.sh` in Windows Git Bash. This requires Git and Python 3.8+ with `venv`. The installer creates `${CODEX_HOME:-$HOME/.codex}/skills/geo` and dedicated `geo-*` skills. Open a new Codex conversation and ask: `Use $geo to audit https://example.com`.

For editing a project: `Use $geo to audit this site, implement safe high-priority fixes, and verify them.` Review proposed business claims before publishing. See the [README](../README.md) for setup and limitations.
