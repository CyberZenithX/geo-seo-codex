# Skills and reference checklists

The main `geo` skill selects tasks by user intent. Focused `geo-*` skills cover audits, citability, crawler access, llms.txt, brand mentions, platforms, schema, technical SEO, content, reports, PDF, prospects, proposals, comparisons, and updates. Read a focused `SKILL.md` when that area is needed.

The five files in `agents/` are reference checklists for AI visibility, platforms, technical SEO, content, and schema. They are bundled under the installed `geo/agents/` path and are not registered Codex subagents. Use their methods without assuming concurrent execution.
